# Vedup has moved

Active development continues in the independent
[Vedup repository](https://github.com/vedprakash2302/Vedup).

Existing Vedup installations can move to the new update channel without
reconfiguring the machine:

```bash
vedup update
```

The final bridge release and its immutable assets remain available here for
existing installations. New installations should use:

```bash
bash -c "$(curl -fsSL https://github.com/vedprakash2302/Vedup/releases/latest/download/bootstrap)"
```

This repository is archived and receives no further development.
